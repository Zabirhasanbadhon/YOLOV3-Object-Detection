# YOLOv3 Object Detection Using OpenCV

## 📌 Project Overview
This project uses the YOLOv3 deep learning model and OpenCV to detect objects in an image. It draws bounding boxes and class labels around detected objects and saves the result as `output.jpg`.

## ✨ Features
- Detect multiple objects in an image.
- Draw bounding boxes and object labels.
- Filter detections using confidence thresholds.
- Save the processed image.

## 📋 Requirements
- Python 3
- OpenCV
- NumPy
- YOLOv3 model files (`yolov3.cfg` and `yolov3.weights`)
- COCO class names (`coco.names`)

## Installation

Install the required libraries:

```bash
pip install opencv-python numpy
```

## Usage

1. Place the YOLOv3 model files and input image in the project directory.
2. Update the file paths in the Python script.
3. Run the program:

```bash
python yolov3_object_detection.py
```

The detected image will be saved as `output.jpg`.
